# Tic Tac Toe — Neon

Play with a friend 👥 or challenge the unbeatable computer 🤖.

Demo: open `index.html` in a browser.

<img src="./demo.gif">

## Features
- 2 Players + vs Computer modes
- 3 difficulties: Easy / Medium / Impossible (minimax + alpha-beta pruning)
- Choose X (first) or O (second)
- Neon UI, winning strike-through line, confetti 🎉
- Scoreboard saved in `localStorage`
- Fully responsive, zero libraries — pure HTML • CSS • JS
